神奇宝贝桌宠 · 使用说明
================================================

支持 macOS（Apple 芯片 / Intel 芯片）与 Windows 10/11 64 位


一、第一次打开
------------------------------------------------

【macOS】
  1. 把「神奇宝贝.app」拖进「应用程序」文件夹
  2. 首次双击会被系统拦下，提示"Apple 无法验证…是否包含恶意软件"。
     这是因为没买 Apple 开发者签名（一年 99 美元），不是文件有问题
  3. 点「完成」（千万别点「移到废纸篓」，那是删除）
  4. 打开「系统设置 → 隐私与安全性」，往下滚到「安全性」那一栏，
     会看到"已阻止使用「神奇宝贝」"，点旁边的「仍要打开」，输入开机密码
  5. 回到「应用程序」，再双击一次，这次弹窗里点「仍要打开」

  更快的办法：打开「终端」，执行下面这行，然后直接双击
     xattr -dr com.apple.quarantine /Applications/神奇宝贝.app

  放行一次就够了，以后都能正常打开。

【Windows】
  1. 把整个 TogepiPet 文件夹放到一个固定位置，比如 D:\TogepiPet
     不要放桌面（容易误删），也不要直接在压缩包里双击
  2. 双击 TogepiPet.exe
  3. 如果弹出"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」

装好之后它会出现在屏幕底部，走两步跟你打个招呼。


二、怎么玩
------------------------------------------------

  轻点一下            冒爱心，心情 +3
  在它身上来回蹭      摸头：压扁弹回、冒爱心、持续涨心情
  1.5 秒内连点三下    生气，转身背对你
  按住拖动 → 甩出去   抓起来挣扎、重力坠落、撞屏幕边缘弹三下，
                      摔太狠了会生气
  托盘 → 收进球       变成精灵球晃三晃，点一下"噗"地出来
  托盘 → 飞一飞       会飞的宝可梦升到半空漂一圈，落地有缓冲
  托盘 → 喂食 🍞      饱食度 +35
  托盘 → 玩耍 🎾      心情 +25
  托盘 → 打盹 😴      强制睡觉


三、它自己会做什么
------------------------------------------------

  · 散步，往左走就朝左看
  · 偶尔跟着你的鼠标跑
  · 跨屏走到另一块显示器（有多屏时）
  · 深夜自己打盹，下雨天懒得动
  · 饿了冒话提醒你，心情差了会闹别扭
  · 发呆时打哈欠、抓痒
  · 发呆时突然放自己的专属招式
  · 悬空飞行时，地上的影子随高度缩小变淡


四、专属动作
------------------------------------------------

1025 只每只都有专属招式。从各世代的升级招式表里挑本系招，
威力跟着进化阶段走 —— 妙蛙种子是藤鞭、水箭龟才是加农水炮、
皮卡丘是十万伏特。

428 种不同招式：粒子形状跟着招式属性走，颜色从这只自己的
精灵图里取。同为水系，杰尼龟和鲤鱼王的特效也不一样。

手动放：托盘 →「专属动作 ✨」


五、异色
------------------------------------------------

1025 只全都有异色版。托盘 →「异色 ✨」，三档可选：

  自动（1/128 彩蛋）  默认。1025 只里正好 8 只是异色，
                      每只的结果是固定的，切来切去不会变
  总是异色            当前这只强制显示异色版
  始终正常            当前这只强制显示普通版

设置会记住，重启后保持。


六、大小 / 换宠物 / 图鉴
------------------------------------------------

  托盘 →「大小」        小 / 中 / 大
  托盘 →「随机一只 🎲」  从 1025 只里随机换一只
  托盘 →「看介绍 📖」    弹一张故事卡
  托盘 →「设置…」        图鉴：可按属性（18 种）、世代、名字、
                         编号搜索，按 540 条进化链展示


七、数据存在哪
------------------------------------------------

  macOS     ~/Library/Application Support/神奇宝贝/
  Windows   %APPDATA%\神奇宝贝\

里面有两个文件：
  pet-state.json   存档：当前是哪只、饱食度、心情、大小、异色设置
  app.log          运行日志，出问题时看这里

备份就复制整个文件夹；换电脑时把它拷到同样位置就行。


八、常见问题
------------------------------------------------

Q: macOS 提示"无法验证开发者"，弹窗里没有「打开」按钮
A: 新版 macOS 已经不给这个按钮了，只能走系统设置。
   点「完成」→「系统设置 → 隐私与安全性」→ 在「安全性」那一栏
   点「仍要打开」→ 输入密码 → 再双击一次。
   或者终端执行：xattr -dr com.apple.quarantine /Applications/神奇宝贝.app

Q: 宠物掉到任务栏下面，只剩声音找不到
A: 0.2.7 修过这个问题（地面高度算错导致一路往下掉），升级到最新版即可。

Q: 宠物一闪一闪，还有残影
A: 0.2.8 修过（Windows 把透明窗口误判成"被遮挡"就暂停绘制），升级即可。

Q: 托盘图标是空白的
A: 0.2.7 之前的版本打包时漏了图标文件，升级即可。

Q: 双击没反应，也看不到进程
A: 先看 app.log 最后几行。常见原因是上一次的实例还占着单实例锁，
   重启电脑或结束残留进程后再开。

Q: 没有声音
A: 先确认托盘菜单里的「叫声」是勾上的，再看系统音量和静音键。
   有些系统会把新应用的音量单独调成 0。

Q: 怎么开机自启 / 怎么关掉
A: 托盘 →「设置…」→ 打开或关闭「开机自启」。同一处控制。

Q: 怎么更新
A: 托盘 →「检查更新 ⟳」，或者启动 8 秒后自动查一次。
   Windows 版会跳到下载页，手动下载解压覆盖就行，存档不会丢。

Q: 怎么完全卸载
A: 1) 托盘 → 退出
   2) 删掉 app（或整个 TogepiPet 文件夹）
   3) 删掉「数据存在哪」里那个文件夹
   开过自启的，先在设置里把「开机自启」关掉再删。

Q: 能改吗？能二次分发吗？
A: 代码是开源的，随便看随便改。
   但宝可梦相关的形象、名称、叫声版权归 Nintendo / Game Freak /
   The Pokémon Company，自己玩和学习没问题，别拿去卖。
