神奇宝贝桌宠 · 使用说明
================================================

支持 macOS（Apple 芯片 / Intel 芯片）与 Windows 10/11 64 位
界面支持中文 / English（设置页 →「语言」切换）


一、第一次打开
------------------------------------------------

【macOS】
  1. 把「神奇宝贝.app」拖进「应用程序」文件夹
  2. 首次双击会被系统拦下，提示"Apple 无法验证…是否包含恶意软件"。
     这是因为没买 Apple 开发者签名（一年 99 美元），不是文件有问题
  3. 点「完成」（千万别点「移到废纸篓」，那是删除）
  4. 打开「系统设置 → 隐私与安全性」，往下滚到「安全性」那一栏，
     会看到"已阻止使用「神奇宝贝」"，点旁边的「仍要打开」，输入开机密码
  5. 回到「应用程序」，再双击一次，这次弹窗里点「仍要打开」

  更快的办法：打开「终端」，执行下面这行，然后直接双击
     xattr -dr com.apple.quarantine /Applications/神奇宝贝.app

  放行一次就够了，以后都能正常打开。

【Windows】
  1. 把整个 TogepiPet 文件夹放到一个固定位置，比如 D:\TogepiPet
     不要放桌面（容易误删），也不要直接在压缩包里双击
  2. 双击 TogepiPet.exe
  3. 如果弹出"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」

装好之后它会出现在屏幕底部，走两步跟你打个招呼。


二、怎么玩
------------------------------------------------

  轻点一下            冒爱心，心情 +3
  在它身上来回蹭      摸头：压扁弹回、冒爱心、持续涨心情
  1.5 秒内连点三下    生气，转身背对你
  按住拖动 → 甩出去   抓起来挣扎、重力坠落、撞屏幕边缘弹三下，
                      摔太狠了会生气
  托盘 → 收进球       变成精灵球晃三晃，点一下"噗"地出来
  托盘 → 飞一飞       会飞的宝可梦升到半空漂一圈，落地有缓冲
  托盘 → 喂食 🍞      食物从上面掉到嘴边，一口吃掉，冒爱心
  托盘 → 玩耍 🎾      球弹出去又弹回来，它会扑腾着去追
  托盘 → 打盹 😴      强制睡觉


三、它自己会做什么
------------------------------------------------

  · 散步，往左走就朝左看
  · 偶尔跟着你的鼠标跑
  · 跨屏走到另一块显示器（有多屏时）
  · 深夜自己打盹，下雨天懒得动
  · 饿了冒话提醒你，心情差了会闹别扭
  · 发呆时打哈欠、抓痒
  · 发呆时突然放自己的专属招式
  · 悬空飞行时，地上的影子随高度缩小变淡


四、专属动作
------------------------------------------------

1025 只每只都有专属招式。从各世代的升级招式表里挑本系招，
威力跟着进化阶段走 —— 妙蛙种子是藤鞭、水箭龟才是加农水炮、
皮卡丘是十万伏特。

428 种不同招式：粒子形状跟着招式属性走，颜色从这只自己的
精灵图里取。同为水系，杰尼龟和鲤鱼王的特效也不一样。

手动放：托盘 →「专属动作 ✨」


五、异色
------------------------------------------------

1025 只全都有异色版。设置页 → 「异色」，三档可选：

  自动（1/128 彩蛋）  默认。1025 只里正好 8 只是异色，
                      每只的结果是固定的，切来切去不会变
  总是异色            当前这只强制显示异色版
  始终正常            当前这只强制显示普通版

设置会记住，重启后保持。


六、大小 / 换宠物 / 图鉴
------------------------------------------------

  托盘 →「看介绍 📖」    弹一张故事卡
  图鉴卡片右上角 ♡      点一下收藏，顶部「♥ 收藏」可以只看收藏的
  托盘 →「设置…」        图鉴页：按属性（18 种）、世代、名字、
                         编号搜索，按 540 条进化链展示；
                         设置页：大小、异色、自动换、语言等

  设置页 →「大小」       小 / 中 / 大
  设置页 →「随机一只」   从 1025 只里随机换一只
  设置页 →「自动换一只」 关闭 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 3 小时，
                         到点自己换一只新的出来，不会连续换到同一只


七、等级与进化
------------------------------------------------

经验从哪来：
  喂食 +60    玩耍 +45    摸头 +2    放招式 +25
  挂着不动每分钟 +10（专注模式下不加）

每 100 点经验升 1 级。等级够了就会进化：

  妙蛙种子 Lv.16 → 妙蛙草 Lv.32 → 妙蛙花
  杰尼龟   Lv.16 → 卡咪龟 Lv.36 → 水箭龟

进化时会白闪一下、换形态、叫一声，图鉴里自动记下。
亲密度类（伊布等）按 Lv.20 算，通信类按 Lv.30，道具和地点类
简化成 Lv.25。伊布这种有多条分支的，会随机挑一种进化。


八、成就
------------------------------------------------

设置页 →「查看徽章 🏆」会打开成就页，共 14 个成就，每个都有徽章：

  初次见面 / 串门儿 / 见多识广 / 博物学家 / 图鉴全开
  异色猎人 / 异色收藏家 / 初出茅庐 / 招式大师
  饲养员 / 摸头狂魔 / 投掷训练 / 老朋友

解锁时会冒出来并叫一声，徽章也会从灰变彩：
遇见过多少只、见过几只异色、连续陪伴多少天、放了多少次招式。


九、专注模式
------------------------------------------------

设置页 →「专注模式」。打开后它不跑、不冒话、不挡鼠标，
饿了也不会来烦你。开会、录屏、打游戏时打开，关掉后恢复原样。


十、番茄钟
------------------------------------------------

设置页 →「番茄钟」→ 25 分钟或 45 分钟。

到点它会冒出来喊你起来动一动（这时候就算开着专注模式也会叫你），
然后进入 5 分钟休息，休息结束再提醒一次。


十一、拍照分享
------------------------------------------------

设置页 →「拍照分享」生成一张图鉴卡 PNG：

  左边是大图（异色会盖一枚金色「✨ 异色」标记），
  右边是编号、名字、分类、属性、专属招式、图鉴描述，
  底部署名和日期。

保存到「图片」文件夹，发朋友圈、发 Discord 都行。


十二、数据存在哪
------------------------------------------------

  macOS     ~/Library/Application Support/神奇宝贝/
  Windows   %APPDATA%\神奇宝贝\

里面有两个文件：
  pet-state.json   存档：当前哪只、等级经验、饱食度、心情、
                   大小、异色、语言、自动切换间隔、成就进度
  app.log          运行日志，出问题时看这里

备份就复制整个文件夹；换电脑时把它拷到同样位置就行。


十三、常见问题
------------------------------------------------

Q: macOS 提示"无法验证开发者"，弹窗里没有「打开」按钮
A: 新版 macOS 已经不给这个按钮了，只能走系统设置。
   点「完成」→「系统设置 → 隐私与安全性」→ 在「安全性」那一栏
   点「仍要打开」→ 输入密码 → 再双击一次。
   或者终端执行：xattr -dr com.apple.quarantine /Applications/神奇宝贝.app

Q: 宠物掉到任务栏下面，只剩声音找不到
A: 0.2.7 修过这个问题（地面高度算错导致一路往下掉），升级到最新版即可。

Q: 宠物一闪一闪，还有残影
A: 0.2.8 修过（Windows 把透明窗口误判成"被遮挡"就暂停绘制），升级即可。

Q: 托盘图标是空白的
A: 0.2.7 之前的版本打包时漏了图标文件，升级即可。

Q: 双击没反应，也看不到进程
A: 先看 app.log 最后几行。常见原因是上一次的实例还占着单实例锁，
   重启电脑或结束残留进程后再开。

Q: 没有声音
A: 先确认设置页里的「叫声」是打开的，再看系统音量和静音键。
   有些系统会把新应用的音量单独调成 0。

Q: 怎么开机自启 / 怎么关掉
A: 托盘 →「设置…」→「设置」标签页，里面可以开关「开机自启」。

Q: 怎么更新
A: 设置页 →「检查更新」，或者启动 8 秒后自动查一次。
   Windows 版会跳到下载页，手动下载解压覆盖就行，存档不会丢。

Q: 换了电脑，等级和成就会丢吗
A: 会跟着存档走。把「数据存在哪」里那个文件夹整个拷过去就行。

Q: 怎么完全卸载
A: 1) 托盘 → 退出
   2) 删掉 app（或整个 TogepiPet 文件夹）
   3) 删掉「数据存在哪」里那个文件夹
   开过自启的，先在设置里把「开机自启」关掉再删。

Q: 能改吗？能二次分发吗？
A: 代码是开源的，随便看随便改。
   但宝可梦相关的形象、名称、叫声版权归 Nintendo / Game Freak /
   The Pokémon Company，自己玩和学习没问题，别拿去卖。


十三点五、更多小惊喜
------------------------------------------------

右键宠物
  不用跑到菜单栏，直接在它身上点右键，就能喂食、玩耍、
  放招式、看介绍。

性格
  每只有自己的性格：开朗（跑得快）、慵懒（走得慢、爱睡）、
  胆小（你一靠近就跑）、傲娇（摸它会哼）、贪吃（饿得快）、
  爱睡。设置页里能看到当前这只是什么性格。

蛋
  走着走着会捡到一颗蛋（大概走十来分钟）。点一下蛋就孵，
  孵出来的是你还没遇见过的宝可梦 —— 想凑图鉴就靠它了。

串门的宝可梦
  隔一阵子会有别的宝可梦从屏幕边跑过来待一会儿，然后又跑走。
  设置页里可以关掉。

每日签到
  每天第一次打开会送 50 点经验，连续签到 7 天解锁「每日打卡」成就。

它也会累
  电脑很忙（内存吃紧）的时候，它走得慢、会冒汗、偶尔说
  「电脑好烫…」。下雪会喊冷，打雷会被吓一跳。

十三点七、报告、游戏和提醒
------------------------------------------------

陪伴报告
  托盘 →「设置…」→ 设置页 →「陪伴报告 📊」，会弹一张卡：陪你多少天、累计多少小时、
  走过多少米、喂了多少次、摸头多少次、孵了几颗蛋……
  底下「保存成图片」可以存到桌面。

接球小游戏
  托盘 →「设置…」→ 设置页 →「接球小游戏 🎮」，它会自己跑过去接掉下来的球，你在旁边看着就行。
  接住几个给几个的经验，最后会告诉你接住多少、漏掉多少。

久坐 / 喝水提醒
  坐满 45 分钟会喊你起来动一动，每小时提醒喝水。
  （专注模式下不打扰）

生日和节日
  第一次打开的那天是它的生日，每年那天会冒蛋糕。
  圣诞、元旦、情人节、劳动节、国庆会自动冒个彩蛋。

鼠标跟随
  你不动的时候，它偶尔会走过来蹲在你光标旁边。

十三点九、进化石和爬墙
------------------------------------------------

进化石
  每日签到、每次孵蛋都会给一颗进化石（菜单里能看到有几颗）。
  托盘 →「用 XX 石进化 ✨」可以不管等级直接进化，
  石头按它的属性来叫：火之石、水之石、雷之石、叶之石……

趴在屏幕边上
  走到屏幕左右边缘时，它偶尔会顺着边爬上去待一会儿，
  再慢慢滑下来。
